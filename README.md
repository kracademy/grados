# Tribunal de Grados

PWA para puntuar los exámenes de grado (Cinturón Negro, 1r Dan y 2º Dan) del Club Karate Swing con el formato del acta de la FCK.

- Funciona sin conexión. Los datos de los aspirantes se guardan solo en el dispositivo.
- Exportación del histórico a CSV (Excel) y copia completa en JSON para restaurar.
- Imprime la hoja del tribunal ya rellenada.

Este repositorio solo contiene código. Ningún dato de aspirantes se publica aquí.
